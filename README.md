# SkyCast Weather App

A simple weather app for checking current conditions and the five-day forecast for a city.

## Features

- Displays current temperature, feels-like temperature, humidity, wind speed, and pressure
- Shows a five-day forecast
- Searches for cities by name
- Loads Lagos weather when the app opens
- Displays loading and error messages

## Run locally

Open `index.html` in a browser. An internet connection is required to retrieve weather data.

## Data

Weather and location data are provided by [Open-Meteo](https://open-meteo.com/) APIs.

## Built with

HTML, CSS, and vanilla JavaScript
